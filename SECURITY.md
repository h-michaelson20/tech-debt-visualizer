# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

- **Preferred:** Open a [private security advisory](https://github.com/h-michaelson20/tech-debt-visualizer/security/advisories/new) on GitHub.
- **Alternatively:** Email the maintainers (see repo About / maintainer contact if available).

Please include a clear description of the issue, steps to reproduce, and the impact you believe it has.

We will respond within 48 hours and work with you to resolve it. We appreciate responsible disclosure.
